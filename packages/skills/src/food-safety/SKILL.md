# 喜茶食安智能处理工作流

本 Skill 用于处理喜茶品牌的食品安全事件，包括舆情监控、投诉分析、诊断建议和自动回复。

## 触发场景

本 Skill 在以下场景自动触发：

- 喜茶相关食安投诉（异物、变质、食品安全问题）
- 监管部门抽检公告
- 内部质量异常报告
- 顾客咨询与投诉

## 工作流程

### 1. 意图分类 (Intent Classification)

对输入事件进行分类：

| 意图 | 说明 | 处理方式 |
|------|------|----------|
| `食安风险` | 涉及食品安全的事件 | → 诊断分析 → 工单升级 |
| `咨询投诉` | 一般性投诉或咨询 | → 生成回复 → 需审核则升级 |
| `无关` | 与喜茶或食安无关 | → 归档忽略 |

### 2. 诊断分析 (Diagnosis)

对食安风险事件进行合规判断：

- 适用标准：GB 7718、GB 2760、企业 SOP
- 严重程度：高 / 中 / 低
- 根因分析
- 处置建议

### 3. 自动回复 (Reply Generation)

生成结构化回复：

- 安抚话术
- 处置指引
- 升级条件判断

- 所有操作需记录审计日志
